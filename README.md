# 🚀 IM\-CHAT\-SERVER \| Golang 原生TCP即时通讯系统

**基于纯 Golang 原生 TCP 开发的轻量级即时通讯服务**，无框架依赖、无CGO、轻量化、跨平台。完整实现账号体系、好友系统、私聊广播、消息持久化、离线推送、消息撤回、心跳保活、密保找回、单点登录，是一套可直接学习、二次开发的完整 IM 项目。

## 📌 项目简介

本项目基于 Go 原生 `net` 网络库从零开发，实现**自定义二进制 TCP 通信协议**，完美解决 TCP 粘包/拆包问题。内置完整的用户体系、好友体系、私聊群聊、消息持久化、离线消息推送、消息撤回、账号密保找回、心跳保活、单点登录踢线等企业级 IM 基础能力。

全程无第三方Web框架、无CGO依赖，代码轻量化、结构清晰，非常适合 **Golang 网络编程、TCP长连接、并发编程、IM系统设计** 学习实战。

## ✨ 核心功能（最新迭代完整版）

### 🌐 网络与连接机制

- **自定义TCP协议**：4字节大端长度头 \+ 消息体，精准解包，限制单包4096字节防攻击

- **智能心跳保活**：客户端3s心跳ping、服务端10s超时自动踢线，杜绝僵尸连接

- **读写超时防护**：彻底解决TCP半开连接、IO永久阻塞问题

- **单点登录机制**：同一账号异地登录，自动挤下线旧设备

### 👤 账号安全体系

- 账号注册、登录、密码校验

- **bcrypt哈希加密**：密码、密保答案均加密存储，无明文泄露

- **密保问答找回密码**：支持自定义密保问题，自助重置密码

- 账号合法性校验、用户名空格拦截、密码长度校验

### 🤝 好友社交系统

- 发送好友申请、待处理申请列表查看

- 同意 / 拒绝 好友申请，双向好友关系绑定

- 查看好友列表、删除好友功能

- 重复好友、自我添加、非法用户拦截校验

### 💬 消息通讯体系

- **公共全员广播消息**：全局群聊，实时推送所有在线用户

- **点对点私聊**：仅好友可私聊，非好友拦截保护

- **消息持久化存储**：所有私聊消息入库保存

- **离线消息推送**：用户离线消息自动缓存，上线一次性推送未读消息

- **消息撤回功能**：发送者可撤回已发送消息，双向通知、历史记录标记撤回

- **聊天历史记录查询**：支持查询与指定好友全部聊天记录

- 消息发送回显、实时日志记录、异常容错处理

### 🖥️ 客户端交互体验

- 终端清屏重绘UI，菜单常驻，沉浸式聊天体验

- 本地消息缓存，实时刷新聊天列表

- 撤回消息本地动态替换，界面同步更新

- 客户端自主心跳，异常断线自动检测

## 🛠 技术栈

- **开发语言**：Golang 1\.22\+

- **网络模型**：原生 TCP Socket \+ 4字节私有协议

- **并发模型**：Goroutine 高并发 \+ sync\.Mutex 连接安全锁

- **数据存储**：SQLite 纯Go无CGO驱动（modernc\.org/sqlite）

- **安全加密**：bcrypt 密码哈希加密

- **版本管理**：Git \+ GitHub

## ▶️ 快速运行

### 1\. 安装依赖

```bash
go mod tidy

```

### 2\. 启动服务端

```bash
cd server
go run main.go

```

默认监听：`0.0.0.0:8080`，自动生成 `im.db` 数据库文件

### 3\. 启动客户端（可多开模拟多用户）

```bash
cd client
go run main.go

```

## 📝 全部客户端指令手册

登录成功后支持以下所有指令：

- `addfriend|用户名` — 发送好友申请

- `pendinglist` — 查看待处理好友申请

- `acceptfriend|用户名` — 同意好友申请

- `rejectfriend|用户名` — 拒绝好友申请

- `friendlist` — 查看我的好友列表

- `delfriend|用户名` — 删除好友

- `setsecq|问题|答案` — 设置密保问题与答案

- `getsecq|用户名` — 查询用户密保问题（找回密码用）

- `resetpwd|用户名|答案|新密码` — 密保重置密码

- `@用户名 消息内容` — 点对点私聊

- `recall|msgId` — 撤回私聊消息

- `history|用户名` — 查询与好友历史聊天记录

- `ping` — 心跳测试（客户端自动发送）

- **直接输入文字** — 公共频道全员广播

## 🗄️ 数据库表结构

服务启动自动创建4张业务表：

- `users`：用户账号表（用户名、加密密码、密保问题、密保答案）

- `friends`：好友关系表（双向好友绑定）

- `pending_friend`：好友申请表（待处理记录）

- `private_msg`：私聊消息表（内容、发送者、接收者、撤回状态、已读状态、时间）
