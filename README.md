## 📌 项目简介

本项目基于 Go 原生 `net` 网络库实现客户端与服务端之间的 TCP 长连接通信。

通信协议采用：

```text
┌──────────────┬──────────────────────┐
│  4 Byte 长度  │       消息正文        │
└──────────────┴──────────────────────┘
```

其中：

- 前 4 字节使用 BigEndian 编码
- 表示后续消息正文长度
- 服务端限制单个数据包最大为 4096 字节
- 使用 `io.ReadFull` 保证完整读取指定长度的数据

通过自定义长度协议解决 TCP 本身存在的粘包和拆包问题。

# ✨ 核心功能

## 🌐 1. TCP 网络通信

### 自定义通信协议

采用：

```text
4 字节消息长度 + 消息正文
```

例如：

```text
[00 00 00 05][hello]
```

其中 `00 00 00 05` 表示后面的消息正文长度为 `5`。

### TCP 粘包 / 拆包处理

服务端使用 `io.ReadFull()` 确保完整读取协议头和消息正文。

同时设置：

```text
最大数据包：4096 Bytes
```

---

## ❤️ 2. 心跳与连接保活

客户端定期发送心跳消息，服务端检测客户端连接状态。

同时设置：

- Read Timeout
- Write Timeout
- Heartbeat Timeout

用于处理客户端异常退出、TCP 半开连接、网络断开和长时间无响应等情况。

## 🔐 4. 单点登录

同一个账号同时只能保持一个有效登录状态。

当同一账号在其他客户端登录时：

```text
旧连接
   ↓
检测到新登录
   ↓
旧客户端被踢下线
   ↓
新客户端保持在线
```

- 查看好友申请

## 💬 6. 公共广播

客户端直接输入普通文本即可发送公共消息。

例如：

```text
大家好
```

服务端会将消息推送给当前在线客户端。

这里的“广播”属于**应用层广播**，服务端通过维护在线 TCP 连接，将消息分别发送给多个已经建立连接的客户端。

```text
Client A
   │
   ▼
Server
 ├────► Client B
 ├────► Client C
 ├────► Client D
 └────► Client E
```

---

## 👥 7. 点对点私聊

私聊使用：

```text
@昵称 消息内容
```

例如：

```text
@小明 你好
```

服务端根据昵称找到对应用户，并进行点对点消息转发。

只有建立好友关系的用户才能进行私聊。

---

## 💾 8. 私聊消息持久化

所有私聊消息都会保存到 SQLite 数据库。

消息记录包含：

- 消息 ID
- 发送者
- 接收者
- 消息内容
- 消息状态
- 已读状态
- 创建时间

主要字段：

```text
private_msg
├── msg_id
├── sender
├── receiver
├── content
├── status
├── is_read
└── createTime
```

---

## 📴 9. 离线消息

当接收方不在线时：

```text
发送者
   │
   ▼
Server
   │
   ▼
SQLite
   │
   │ 离线保存
   ▼
接收者重新登录
   │
   ▼
推送未读消息
```

用户重新登录后可以收到之前积累的离线私聊消息。

---

## ↩️ 10. 消息撤回

发送者可以通过消息 ID 撤回自己的私聊消息：

```text
recall|msgId
```

例如：

```text
recall|123
```

撤回后：

- 消息状态更新
- 聊天记录显示“消息已撤回”
- 对方客户端同步收到撤回结果

只有消息发送者本人可以撤回消息。

# 📜 11. 私聊历史记录

项目支持查看与好友之间的历史私聊记录。

历史记录查询分为：

```text
全部查看
    │
    ├── 按日期精准查询
    │
    └── 按消息 ID 精准查询
```

## 11.1 查看全部聊天记录

```text
history|好友账号ID|all
```

例如：

```text
history|10002|all
```

查询双方之间的全部私聊记录。

---

## 11.2 按日期精准查询

日期查询只需要输入：

```text
YYYY-MM-DD
```

例如：

```text
history|10002|time|2026-09-18|2026-09-18
```

程序会自动将日期扩展为完整的一天：

```text
2026-09-18 00:00:00
        ↓
2026-09-18 23:59:59
```

也可以查询日期范围：

```text
history|10002|time|2026-09-01|2026-09-18
```

表示查询 `2026-09-01` 至 `2026-09-18` 期间双方的私聊记录。

---

## 11.3 按消息 ID 精准查询

```text
history|好友账号ID|msgid|消息ID
```

例如：

```text
history|10002|msgid|123
```

只查询指定消息 ID。

消息 ID 查询仍然限制在当前双方的聊天记录中，不会因为指定其他消息 ID 而读取其他用户之间的聊天记录。

# 🗄️ 数据库

项目使用 SQLite 作为持久化数据库。

SQLite 驱动：

```text
modernc.org/sqlite
```

服务端启动后会自动创建：

```text
im.db
```

主要业务表：

| 表名 | 作用 |
|---|---|
| `users` | 用户账号、密码、昵称、密保信息 |
| `friends` | 好友关系 |
| `pending_friend` | 好友申请 |
| `private_msg` | 私聊消息 |

# ▶️ 快速运行

## 1. 克隆项目

```bash
git clone https://github.com/xulingjunK/im_demo.git
cd im_demo
```

## 2. 下载依赖

```bash
go mod tidy
```

## 3. 启动服务端

```bash
cd server
go run main.go
```

默认监听：

```text
0.0.0.0:8080
```

服务端启动后会自动初始化 SQLite 数据库。

## 4. 启动客户端

重新打开一个终端：

```bash
cd client
go run main.go
```

可以同时启动多个客户端，用于模拟多个用户进行通信。
